# F-Droid Repo Server

Portable, env-driven F-Droid repository that deploys to any S3-compatible storage via rclone.

## Quick Start

### 1. Configure

```bash
cp .env.example .env
# Edit .env with your repo name, S3 credentials, etc.
# Leave KEYSTORE_PASS/KEY_PASS blank -- init auto-generates them.
```

### 2. Add APKs

Drop your signed `.apk` files into `apks/`.

### 3. Publish

**Bare metal** (requires `fdroidserver`, `rclone`, and Android SDK build-tools installed):

```bash
./scripts/init.sh       # generate config.yml + rclone.conf from .env
./scripts/publish.sh    # copy APKs, update index, deploy to S3
```

**Docker:**

```bash
docker compose run --rm fdroid
```

## Directory Structure

```
.env.example        # Template -- copy to .env and fill in
.env                # Your config (gitignored)
scripts/
  init.sh           # Generate config.yml + rclone.conf from .env
  gensecret.sh      # Generate random keystore passwords into .env
  publish.sh        # Full pipeline: copy, update, deploy
  verify.sh         # APK signature verification
  clean.sh          # Reset repo (wipe generated files)
apks/               # Drop APKs here (input)
metadata/           # F-Droid app metadata (auto-generated or manual)
keystore.p12        # Signing keystore (gitignored)
config.yml          # Generated by init.sh (gitignored)
rclone.conf         # Generated by init.sh (gitignored)
repo/               # Generated F-Droid repo output
Dockerfile          # Containerized deployment
docker-compose.yml
```

## Individual Scripts

| Script | Purpose |
|--------|---------|
| `scripts/init.sh` | Reads `.env`, generates `config.yml` and `rclone.conf` (auto-fills blank keystore passwords) |
| `scripts/build.sh` | Copies APKs, verifies signatures, runs `fdroid update` (no deploy) |
| `scripts/publish.sh` | Runs `build.sh` then `fdroid deploy` to push to S3 |
| `scripts/gensecret.sh` | Writes a random `KEYSTORE_PASS` / `KEY_PASS` into `.env` |
| `scripts/keygen.sh` | Generates a signing keystore via `fdroid update --create-key` |
| `scripts/verify.sh` | Verifies APK signatures in `repo/` using `apksigner` |
| `scripts/clean.sh` | Wipes `repo/`, `tmp/`, `cache/`, `metadata/`, `config.yml`, `rclone.conf` for a full reset |

## Bare-Metal Prerequisites

- [fdroidserver](https://f-droid.org/docs/Installing_the_Server_Tools/) (`apt install fdroidserver` or `pip install fdroidserver`)
- [rclone](https://rclone.org/install/)
- Android SDK build-tools (for `apksigner`) -- set `ANDROID_HOME`
- Java 17+

## Environment Variables

All configuration lives in a single `.env` file. See `.env.example` for the full list:

- **Repo identity**: `REPO_NAME`, `REPO_URL`, `REPO_DESCRIPTION`, `REPO_WEB_BASE_URL`
- **Signing**: `KEYSTORE_FILE`, `REPO_KEYALIAS`, `KEYSTORE_PASS`, `KEY_PASS`, `KEYDNAME`
- **S3/rclone**: `S3_REMOTE_NAME`, `S3_PROVIDER`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_REGION`, `S3_ENDPOINT`
